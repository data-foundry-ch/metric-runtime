# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue that contains credentials, tokens,
private data, or exploit details.

Preferred options:

1. Use **GitHub private vulnerability reporting** for this repository if it is
   enabled (Security → Advisories / Report a vulnerability).
2. Otherwise contact the maintainers through the repository’s documented
   private security channel.
